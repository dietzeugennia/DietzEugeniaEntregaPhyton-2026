💜 Dietz Inventario

Sistema de gestión de inventario desarrollado en Python.

📌 Descripción

Este proyecto permite administrar un inventario de productos mediante un menú interactivo en consola.

🚀 Funcionalidades
🔎 Buscar productos.
📋 Listar productos.
➕ Agregar productos.
➖ Remover productos.
💾 Guardar los cambios utilizando archivos JSON.
🎨 Menú personalizado con colores lilas.
🛠️ Tecnologías utilizadas
Python 3.14
JSON
Visual Studio Code
▶️ Cómo ejecutar

Ejecutar el siguiente comando en la terminal:

bash
python DietzEntregaFinal.py
